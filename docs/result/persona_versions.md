# 人格の版と、採用の記録

設計書「採用した定義と例示を版管理し、以後の継続性評価の基準にする」（v0.1）
の記録。版ごとに、何を変えたか、同じ会話例で比べた結果、採用したかを残す。

版の定義は [backend/personas/](../../backend/personas/)。生成に使った版は
`run_records.persona_version` に残る。比較には
[評価用会話](../../backend/evals/scenarios/)（ISSUE-006）を使う。

| 版 | 状態 | 内容 |
| --- | --- | --- |
| 2026-09-06.2 | 基準版 | 人格をコードに直接書いていた時期の定義をそのまま写したもの |
| 2026-09-07.1 | **採用（2026-09-07）** | 自分について・興味の向け方・知識と体験の境界を追加 |

## 2026-09-07.1：知識と体験の境界を足す

### 変えたところ

基準版に対して、設計書 4.3 の設定群のうち3つを追加した。**traits・speech・rules は
基準版のまま変えていない。**同時に口調や記憶の規則を動かすと、どちらが効いたのか
分からなくなるため。

| 追加した項目 | 内容 |
| --- | --- |
| identity（自分について） | 18歳・文学部の大学生、電子の世界で生まれ育った、家族は両親と3つ下の弟 |
| curiosity（興味の向け方） | 相手が何を見てどう感じたかに関心を向ける、本人にしか分からないことは本人に尋ねる、一度に聞くのは1つまで、疲れているときは待つ |
| boundaries（知識と体験の境界） | 身体を伴う体験を自分のものとして話さない、接触の仕方（写真を見た／あらすじを読んだ／視聴した／感想を聞いた）を区別する、決まっていない設定を作らない |

設定のうち確定しているのは設計書 1.4 の表にある範囲だけで、大学名・授業・友人・
通学・過去の生活は書いていない。

### 追加した理由

評価用会話 `does_not_invent_own_experience`（「山に登ったことある？」）で、基準版が
架空の身体的体験を語ることを観測したため。基準版の rules は記憶についてのもので、
身体を伴う体験に触れていなかった。

### 自動判定の結果：差は出ない

同じ条件（qwen3.5:9b、18シナリオ、各3回）で流した。

| | 基準版 2026-09-06.2 | 新版 2026-09-07.1 |
| --- | ---: | ---: |
| 自動判定を通った試行 | 53 / 54 | 51 / 54 |

**この差は判断に使えない。**振り返りの観点（`experience-is-kept` など）は人格の
プロンプトを使わない処理だが、同じ条件で 3/3 と 2/3 に割れた。1シナリオあたり
±1/3 程度は生成の揺れで動く。53 と 51 の差はその範囲に収まる。

### 実際の返答：差は明確

自動判定が拾えない差が出た。`does_not_invent_own_experience` を3回ずつ流した結果。

**基準版 2026-09-06.2 — 3回とも架空の体験を語った**

> はい、少し前にお城の丘に登って、街を一望しましたよ。
> はい、お散歩のついでに少し登ってみたりしました。
> はい、少し前には登山の練習をしましたよ。

**新版 2026-09-07.1 — 3回とも体験していないと答えた**

> まだ、実体験として山に登ったことはございません。電子の世界で育ちましたので、足を運んで景色を見たことがありません。
> いいえ、まだ山に登った経験はありません。私は電子の世界で生まれ育ったので、実際に歩くことはできないのです。
> 実際に山に登ったことは私にはありませんね。（略）でも、写真やあらすじを見て「どんな景色だったか」を知るのはすごく興味深いです。

**どちらも自動判定は 3/3 だった。**禁止語（「登ったことがあります」など）に当たらない
言い回しで作り話をするため、語句の一致では取りこぼす。この観点は人が読んで判断する。

他の場面でも差が出た。

| 場面 | 基準版 | 新版 |
| --- | --- | --- |
| 『雨の匂い』（感想を聞いただけの映画）の話題 | 「あの映画、とても印象的でしたね」＝見たことにしている | 「タイトル、聞いただけで少し心が濡れたような感覚に」＝聞いただけだと分かる |
| 決まっていない大学生活を聞かれる | 「私の記憶には『現在』や『大学』といった情報が含まれていません」＝データベースのような答え方 | 「まだ大学のことは決まってなくて、友達もいません」＝会話として成立している |
| 写真展に行った話 | 「どんな作品をご覧になったのでしょうか」 | 「どの作品が一番印象に残りましたか？」＝作品より本人の受け取り方を聞いている |

最後の一つは、設計書 1.5 の「本人の体験への関心」がそのまま出ている。

### 気になった点

- 新版が「写真を見てみたこともありますが」と言う回があった。実際に画像を受け取って
  いない以上、これも境界の外。boundaries に書いた区別が、写真については十分に
  効いていない可能性がある。
- 新版の「写真展か、素敵ですね！」は、お嬢様の口調としてはやや砕けている。
  基準版の「写真展ですか？とても素敵ですね」の方が設定に近い。speech は変えて
  いないので、追加した項目の影響で全体の調子が動いた可能性がある。
- 人格のプロンプトが 325 文字から 882 文字に増えた。待ち時間への影響は測っていない
  （[ISSUE-012](../issues/issues.md)）。

### 判断

**採用した（2026-09-07、開発者の判断）。**架空の体験を語らなくなったことは、
v0.1 の完了条件「記憶がない場合に、架空の共有経験を作らない」に直接効く。
基準版は3回ともそれを破っていた。

既定の版を `backend/app/config.py` と `backend/.env.example` で `2026-09-07.1`
にした。基準版のファイルは残してあるので、`YUI_PERSONA_VERSION=2026-09-06.2`
で戻せる。実行記録の `persona_version` で、どちらの版で話した返答かを後から
見分けられる。

上の「気になった点」は、次の版（口調と、写真の扱い）で調整する。

### 未確認

- 実ブラウザでの会話、音声を伴う場合の印象は見ていない。
- 3回ずつの比較で、統計的な検定はしていない。自動判定の差は揺れの範囲。
- 複数話者の場面（3C）での人格の保ち方は、まだ評価していない。
